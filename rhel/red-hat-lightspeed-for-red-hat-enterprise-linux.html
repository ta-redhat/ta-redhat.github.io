Red Hat Lightspeed for Red Hat Enterprise Linux

What is it?

Red Hat Lightspeed for Red Hat Enterprise Linux (formerly Red Hat Insights) is a proactive, AI-powered monitoring service, included with every RHEL subscription, that analyzes your systems to flag security threats, performance bottlenecks, and misconfigurations before they cause problems.

Rather than waiting for something to break, Lightspeed continuously analyzes your RHEL environment — including applications like SAP and Microsoft SQL Server running on it — and surfaces specific, prioritized issues along with guidance (and sometimes a ready-to-run Ansible Playbook) to fix them.

How does it work?

A lightweight client runs on each RHEL host and reports system data to Red Hat Lightspeed, either as a hosted SaaS service in the Red Hat Hybrid Cloud Console or, for disconnected/regulated environments, locally through Red Hat Satellite. Lightspeed analyzes that data against known risks, vulnerabilities, and best practices, then shows you prioritized recommendations. For many issues, it can generate a remediation Ansible Playbook you review and run yourself, or — if you're also a Satellite customer with remote execution configured — execute directly at scale.

Why do I need it?

Across a large RHEL estate, manually checking every system for misconfigurations or vulnerabilities isn't realistic — problems surface only after they've caused damage. Lightspeed flips that around: continuous, proactive visibility into exactly which systems are at risk and why, already included in your subscription.

Where do I get it?

Red Hat Lightspeed for RHEL is included at no extra cost with any Red Hat Enterprise Linux subscription — there's nothing separate to buy. If you don't have a RHEL subscription yet, see the main RHEL entry in this project, or contact Red Hat sales: https://www.redhat.com/en/contact.
