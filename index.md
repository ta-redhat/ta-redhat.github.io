# Red Hat (Company)

## What is it?
**Red Hat is an enterprise open source software company that turns community-developed open source projects — Linux, Kubernetes, Ansible, and more — into secure, supported, enterprise-ready products, and has operated as an independent subsidiary of IBM since 2019.**

Founded in 1993, Red Hat first made its name with Red Hat Enterprise Linux and has since grown into a full hybrid cloud software portfolio: an application platform (OpenShift), IT automation (Ansible Automation Platform), virtualization (OpenShift Virtualization), AI infrastructure (Red Hat AI), and open source supply chain security (Lightwell). It's not a typical proprietary software vendor — it doesn't sell closed, licensed code — and it's not a hosting/cloud provider either, since its products are designed to run on any infrastructure a customer chooses. Instead, Red Hat sits in a specific niche: it's the company enterprises pay to make open source software production-ready, secure, and supported long-term. It's trusted by more than 90% of Fortune 500 companies and remains headquartered in Raleigh, North Carolina, even after joining IBM.

## How does it work (open source, etc.)?
Red Hat follows an "upstream first" model: instead of writing proprietary software in isolation, it participates directly in open source communities (the Linux kernel, Kubernetes, Ansible, vLLM, PyTorch, and many others), contributing code back to those projects rather than forking and closing it off. From that shared, fast-moving upstream code, Red Hat builds its own hardened, enterprise-ready distributions — testing extensively, certifying compatibility with hardware and software partners, backporting security patches, and committing to a predictable, multi-year support lifecycle. Customers then pay Red Hat not for a software license (the underlying code is typically free and open source already) but for a **subscription** that includes that ongoing support, security patching, certification, and lifecycle guarantee. This is why Red Hat is often described as selling trust, stability, and support around open source, rather than selling the software itself.

## Why do I need its products?
Open source software is powerful but comes with no guarantees on its own — no vendor to call when something breaks, no certified compatibility, no committed security-fix timeline. Red Hat removes that risk: you get open source's innovation with a vendor's accountability, patching, and long-term support behind it.

It matters most if you're:

- Running production workloads on Linux
- Modernizing or scaling application development
- Automating IT operations across a large or complex environment
- Deploying AI into production
- Managing exposure to open source vulnerabilities

## Where do I find those products?

- **redhat.com** is the main marketing and sales site — each product (Red Hat Enterprise Linux, OpenShift, Ansible Automation Platform, Red Hat AI, Lightwell, and more) has its own product page there with an overview, pricing/licensing direction, and a path to buy or contact sales. Start at [https://www.redhat.com/en](https://www.redhat.com/en) for the full portfolio, or go directly to the **Red Hat Store** ([https://www.redhat.com/en/store](https://www.redhat.com/en/store)) for self-serve purchases (currently RHEL Server/Workstation and a few other products) or **Contact Sales** ([https://www.redhat.com/en/contact](https://www.redhat.com/en/contact)) for everything else.
- **developers.redhat.com** is the destination for hands-on access: a free Red Hat Developer membership unlocks no-cost product subscriptions, trials, a Developer Sandbox (for immediate hands-on access to OpenShift and other products), documentation, learning paths/guided learning, and a technical community — ideal if you want to try or learn the technology before (or instead of) engaging sales. Start at [https://developers.redhat.com/](https://developers.redhat.com/).
