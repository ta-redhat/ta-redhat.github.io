Red Hat Automation Coding Assistant — What / How / Why / Where

What is it?

The Red Hat Automation coding assistant (formerly branded Red Hat Ansible Lightspeed) is a generative AI service, included with Ansible Automation Platform, that turns natural-language prompts into trusted Ansible YAML code — single tasks, full playbooks, or roles.

It's built for the people writing automation content day to day: instead of starting from a blank file, you describe what you want in plain English inside your code editor and get working Ansible code back, following best practices.

How does it work?

The coding assistant is delivered directly inside your editing environment via the Ansible VS Code extension. You type a natural-language prompt (e.g., "install and start nginx, then open port 80"), and it generates the corresponding Ansible task, multi-task sequence, playbook, or role. It connects to a large language model of your choice — IBM watsonx Code Assistant, Google Gemini (Vertex), or another OpenAI-compliant provider — which can be deployed on-premise, hybrid, or as SaaS. (A related but separate capability, the automation intelligent assistant, is a chat assistant embedded in the Ansible Automation Platform UI itself, helping administrators with platform configuration and troubleshooting rather than writing playbooks.)

Why do I need it?

Writing correct, best-practice Ansible YAML from scratch takes real expertise, and it's a common bottleneck as organizations try to scale automation faster than they can train or hire experienced Ansible authors. The coding assistant lowers that barrier: less experienced team members can translate their intent into working automation content immediately, while experienced authors move faster by skipping repetitive boilerplate — directly addressing the Ansible skills gap that otherwise slows automation adoption.

Where do I get it?

The coding assistant service is included with your Ansible Automation Platform subscription; you only pay separately for usage of your chosen connected LLM provider. If you don't yet have Ansible Automation Platform, contact Red Hat sales: https://www.redhat.com/en/contact.
