Red Hat OpenShift

What is it?

Red Hat OpenShift is an enterprise application platform, built on Kubernetes, for building, deploying, running, and modernizing containerized applications and AI workloads across hybrid cloud environments.

OpenShift takes open source Kubernetes and wraps it with the security, management tooling, developer experience, and vendor support an enterprise needs to run it in production at scale. It covers the whole application lifecycle — from building new cloud-native apps, to modernizing (rehosting, re-platforming, or refactoring) existing ones, to migrating traditional virtual machines onto the same platform, to deploying and managing predictive and generative AI models via Red Hat OpenShift AI. It's offered in several forms: fully managed cloud services on partner platforms (e.g., Google Cloud), and self-managed editions ranging from an entry-level Kubernetes container runtime up to an "Advanced" tier with multicluster security and management for large, complex environments — plus a VM-only edition for organizations focused purely on virtual machine migration.

How does it work?

At its core, OpenShift runs your applications as containers orchestrated by Kubernetes, which automatically handles scheduling, scaling, networking, and recovery for those workloads across a cluster of machines. Red Hat adds a management console, built-in security controls, and a set of "operators" — add-on components you can enable from a single console to extend the platform, such as OpenShift GitOps and Pipelines for CI/CD, OpenShift Service Mesh and Serverless for microservices/infrastructure management, and OpenShift Observability for real-time monitoring. You can run OpenShift yourself (self-managed) on your own infrastructure or cloud, or let Red Hat/a cloud partner manage it for you as a hosted service — either way, the experience and tooling stay consistent, so teams use the same workflows regardless of where a given cluster lives.

Why do I need it?

Modernizing applications, building cloud-native software, or deploying AI with raw, unmanaged Kubernetes means your team builds and maintains all the security, updates, and tooling itself — a significant ongoing burden and a common source of incidents. OpenShift gives you one supported platform for all of it instead.

It's particularly valuable if you need to:

  • Consolidate multiple application types (containers and VMs) onto one platform
  • Deploy AI/agentic workloads consistently across hybrid cloud
  • Get built-in CI/CD and observability instead of assembling it from scratch

Where do I get it?

OpenShift is not sold through the self-serve Red Hat Store — purchasing typically goes through a sales conversation or a cloud marketplace. To get started, you can contact Red Hat sales: https://www.redhat.com/en/contact, purchase through a cloud marketplace (OpenShift is available as a managed service on partner clouds such as Google Cloud), or work through a Red Hat partner. No-cost trials and pay-as-you-go options are also available for evaluation before committing to a subscription.

Red Hat publishes a central OpenShift pricing comparison page covering all the managed cloud editions side by side; reserved-instance pricing starts as low as $0.076/hour (per 4 vCPU, 3-year contract). See each managed edition's own page in this project (ROSA, ARO, OpenShift Dedicated) for the specific published rates.

Related Products

OpenShift has by far the largest ecosystem of related products of anything in this project — editions, managed-service variants, bundled capabilities, and standalone tools that extend it. Grouped for clarity:

Editions & managed-service variants

  • Red Hat OpenShift Platform Plus — the most complete self-managed edition (adds Advanced Cluster Management, Advanced Cluster Security, Quay, and storage)
  • Red Hat OpenShift Kubernetes Engine — entry-level, lower-cost edition with a reduced feature set
  • Red Hat OpenShift Virtualization Engine — self-managed, VM-only edition
  • Red Hat OpenShift Dedicated — fully managed by Red Hat on AWS or Google Cloud
  • Red Hat OpenShift Service on AWS (ROSA) — native, jointly managed AWS service
  • Azure Red Hat OpenShift (ARO) — native, jointly managed Azure service

Bundled capabilities (included with OpenShift)

  • Red Hat OpenShift Virtualization — run VMs alongside containers on any OpenShift edition
  • Red Hat OpenShift GitOps — Argo CD-based GitOps operator
  • Red Hat OpenShift Pipelines — Tekton-based CI/CD
  • Red Hat OpenShift Service Mesh — Istio-based microservices connectivity/security
  • Red Hat OpenShift Serverless — Knative-based event-driven/scale-to-zero apps
  • Red Hat OpenShift Observability — unified monitoring, logging, and tracing
  • Red Hat OpenShift Dev Spaces — browser-based cloud development environments
  • Red Hat OpenShift AI — AI/ML model and agent lifecycle platform; fully documented under red-hat-ai/red-hat-openshift-ai.md since it's also a core Red Hat AI product

Fleet management & security (Platform Plus components, also available standalone)

  • Red Hat Advanced Cluster Management for Kubernetes — multicluster fleet management and governance
  • Red Hat Advanced Cluster Security for Kubernetes — Kubernetes-native security across build/deploy/runtime
  • Red Hat Quay — enterprise container registry

Developer experience & software supply chain security

  • Red Hat Advanced Developer Suite — bundled developer productivity + supply chain security suite (also connects to Lightwell)
  • Red Hat Developer Hub — Backstage-based internal developer portal
  • Red Hat Trusted Profile Analyzer — SBOM/CVE/VEX risk analysis
  • Red Hat Trusted Artifact Signer — cryptographic artifact signing/verification

Local development & AI assistance

  • Red Hat OpenShift Local — free, single-node OpenShift cluster for your laptop
  • Red Hat OpenShift Lightspeed — generative AI assistant built into the OpenShift console
