# Red Hat OpenShift Local

## What is it?
**Red Hat OpenShift Local (formerly Red Hat CodeReady Containers) runs a minimal, preconfigured OpenShift cluster directly on your laptop or desktop, so you can develop and test against a real OpenShift environment without any server infrastructure.**

It's the quickest way to get a working OpenShift cluster for local development — no cloud account, no shared cluster, no waiting on IT to provision anything.

## How does it work?
OpenShift Local packages a single-node OpenShift Container Platform cluster that runs locally on Linux, macOS, or Windows, using Podman for a slim, minimal-download container runtime. It comes with a local Docker-compatible registry, integrated service mesh and serverless capabilities, templates, and a connection to VS Code via the OpenShift Connector — everything needed to build container images and run them in Kubernetes-hosted containers on your own machine, whatever programming language you're using.

## Why do I need it?
Developing against a shared, remote cluster for every test iteration is slow and creates contention with other teams — and spinning up cloud infrastructure to test a small change is overkill. OpenShift Local gives each developer their own disposable OpenShift environment on their own machine, to build and iterate quickly before pushing to a shared or production cluster.

## Where do I get it?
Free to download and use for local development/testing (not intended for production use). Download directly: [https://developers.redhat.com/products/openshift-local](https://developers.redhat.com/products/openshift-local).
