# Red Hat OpenShift Virtualization Engine

## What is it?
**Red Hat OpenShift Virtualization Engine is a self-managed OpenShift edition focused exclusively on deploying, managing, and scaling virtual machines — without the container-orchestration features of broader OpenShift editions.**

It's built for organizations re-platforming VMs off another virtualization solution who don't need (and don't want to pay for) the ability to run containers and VMs together on the same clusters.

## How does it work?
Virtualization Engine provides the same proven VM functionality found in full OpenShift (built on the open source KVM hypervisor) in a streamlined, VM-only package with aligned pricing. It includes the migration toolkit for virtualization to help organizations move VMs from other virtualization environments with minimal downtime, and works with Red Hat Ansible Automation Platform to automate VM migration at scale along with related infrastructure like networks and storage. If you later decide you do want to run containers alongside your VMs, you can move up to editions like OpenShift Kubernetes Engine or Container Platform, which include virtualization as part of a broader platform.

## Why do I need it?
Migrating off legacy virtualization is a large project on its own, and many teams doing that migration have no near-term need for container orchestration. Virtualization Engine gives you Red Hat's VM management and migration tooling at a price matched to "VMs only," with room to grow into broader OpenShift editions later.
