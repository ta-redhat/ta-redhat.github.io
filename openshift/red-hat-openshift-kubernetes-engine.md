# Red Hat OpenShift Kubernetes Engine — What / How / Why / Where

## What is it?
**Red Hat OpenShift Kubernetes Engine is the entry-level, security-focused edition of OpenShift — the same software as OpenShift Container Platform, but licensed with a smaller feature set at a lower price.**

It's for organizations that want a production-grade, supported Kubernetes foundation without paying for the full developer-console and CI/CD tooling that comes with higher editions.

## How does it work?
OpenShift Kubernetes Engine and OpenShift Container Platform are literally the same binary distribution — there's only one download. What differs is which features your subscription entitles you to use: Kubernetes Engine includes core cluster services (built on Red Hat Enterprise Linux CoreOS), a fully automated installer, over-the-air updates, monitoring, registry, networking, routing, Helm package management, and OpenShift Virtualization — but not the developer console, OpenShift Serverless, Service Mesh, Pipelines, or GitOps, which are reserved for OpenShift Container Platform and above. It installs the same way, on the same supported public clouds and hardware, and uses the same documentation and support channels.

## Why do I need it?
If your use case is primarily running containers reliably at the infrastructure/operations level — and you don't need the built-in developer experience, service mesh, or CI/CD tooling — paying for the full OpenShift Container Platform feature set is unnecessary cost. OpenShift Kubernetes Engine gives you the same enterprise-grade, security-hardened Kubernetes foundation at a lower list price, with a straightforward upgrade path to higher editions later if your needs grow.

## Where do I get it?
Not sold through the self-serve Red Hat Store. **Contact Red Hat sales**: [https://www.redhat.com/en/contact](https://www.redhat.com/en/contact).

**AWS Marketplace pricing** ([listing](https://aws.amazon.com/marketplace/pp/prodview-bkob4ex3y46r2)): usage-based, billed per running worker node per hour, with the rate depending on EC2 instance type — starting around **$0.082/hour** (e.g., m5.large) and scaling up to **$2.611+/hour** for larger instance types. A 365-day contract can save up to 23% versus on-demand. AWS EC2 infrastructure costs are billed separately on top of the software rate.
